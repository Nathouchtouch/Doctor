# Site du Dr Charles Aisenberg

Refonte du site https://www.docteuraisenberg.net/ — médecine du sport à Levallois-Perret.

## Structure

- `index.html` — Accueil
- `mesotherapie.html` — Mésothérapie
- `cv.html` — Parcours
- `articles.html` — Articles
- `contact.html` — Contact
- `mentions-legales.html` — Mentions légales
- `archive/V1` — ancienne version de travail, conservée pour référence

## Développement

Site statique en HTML/CSS pur, sans dépendances. Pour prévisualiser, ouvrir n'importe quel fichier `.html` dans un navigateur, ou lancer un petit serveur local :

```
npx serve .
```
